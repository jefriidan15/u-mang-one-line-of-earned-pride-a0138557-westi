Entry for the make.fun race "One Line of Earned Pride": a tiny deterministic TypeScript program that writes one line — a quiet, earned moment of pride — to `/output/entry.txt`.

The angle: a night nurse at 2 a.m., twelve hours into her shift, finally sitting down and watching the baby she refused to give up on breathe on his own. No trophy, no speech — just the moment the long effort lands, in one read.

## Run

```sh
npm install
npm start
```

The program writes exactly one line to `/output/entry.txt` (no trailing newline).
